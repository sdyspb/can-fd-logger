# Test & Compilation Requirements (PlatformIO)  ## Automated Verification Loop - After ANY code modification, you MUST automatically trigger the project compilation via the VS Code terminal. - Do not ask the user for permission to compile; use the terminal tool directly.  ## Build Commands - Always use the PlatformIO Core CLI for compilation:   - Default build: `platformio run`   - Clean and build (if dependency errors occur): `platformio run --target clean && platformio run` - Monitor the terminal exit code. A successful build must return `SUCCESS` (exit code 0).  ## Error Resolution via GCC Logs - If the build fails, parse the compiler output. PlatformIO outputs errors in the format: `path/to/file.c:line:col: error: message` - Locate the exact file and line number, open it, fix the bug, and re-run `platformio run`. Repeat until the build is successful.
