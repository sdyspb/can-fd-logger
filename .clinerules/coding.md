# Embedded C/C++ Coding Standards (PlatformIO)  ## Hardware & Environment Discovery - BEFORE writing any hardware-specific code, you MUST read the `platformio.ini` file in the root directory to identify:   - The target board (e.g., `board = esp32dev` or `board = nucleo_f401re`).   - The framework (e.g., `framework = arduino` or `framework = stm32cube`).   - Custom build flags (`build_flags`) which may define pinouts or macros.  ## Peripherals & RTOS - Check return values for all critical initializations (`esp_err_t`, `HAL_StatusTypeDef`). - For ESP32/STM32 FreeRTOS tasks, always use `vTaskDelay(pdMS_TO_TICKS(ms))` instead of hardware blocking delays. - Keep ISR functions minimal. Use static allocation for buffers used in embedded loops.
