# PlatformIO System Architecture  ## Project Directory Layout - Strictly adhere to the standard PlatformIO layout:   - `src/` — Main application source code.   - `include/` — Global header files.   - `lib/` — Custom project-specific libraries/drivers.   - `.pio/` — Build cache and managed libraries (NEVER modify files inside this folder).  ## Dependency Management - If a specific sensor or protocol library is missing, do not implement it from scratch if it exists in the registry.  - You may suggest adding a library to the `lib_deps` section inside `platformio.ini`.
