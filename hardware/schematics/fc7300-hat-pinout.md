# Пинаут контроллера FC7300F8MDT (BGA320) для нового шилда

Проект распределения выводов разработан на основе оригинальной таблицы мультиплексирования `FC7300F8MDT Pinout` (Rev. 1.3) и требований к новому шилду. Аппаратный модуль `FLEXCAN0` назначен в качестве канала с поддержкой пробуждения (Wakeup), так как его выводы привязаны к энергонезависимому домену питания `PD0`. Высокоскоростные интерфейсные линии RGMII разведены строго на специализированные выводы типа `UHS pad` и `HS pad` для обеспечения целостности сигналов на частоте 125 МГц.

Перечень всех необходимых аппаратных интерфейсов, которые заложены в архитектуру разрабатываемой платы:

- **1 × RGMII** (Высокоскоростной интерфейс Gigabit Ethernet)
- **1 × FLEXCAN** с поддержкой пробуждения (Wakeup CANFD)
- **7 × FLEXCAN** стандартных (Простые каналы CANFD)
- **1 × UART** (Выделенная отладочная консоль на базе модуля FCUART1)
- **1 × I2C** (Шина данных I2C1 для работы с внешней системной EEPROM)
- **1 × SPI** (Интерфейс FCSPI2 для подключения внешней энергонезависимой памяти NOR Flash)

> ⚠️ **Предупреждение:** Данный набор интерфейсов полностью исчерпывает требования технического задания. Все остальные встроенные блоки контроллера (АЦП, компараторы, таймеры FTU/eFTU/TPU, а также интерфейсы LIN, SENT, MSC и SDDF) не выводятся на разъемы шилда и переводятся в неактивное состояние (Clock Gating) для минимизации энергопотребления.

## 2. Свободные (неиспользуемые) ресурсы контроллера

Все нижеперечисленные ресурсы кристалла полностью свободны на новом шилде, не имеют пересечений по ножкам с активными интерфейсами и могут быть оставлены неподключенными либо выведены на тестовые точки.

- **Свободные GPIO:** 206 выводов (из 248 физически доступных в данном корпусе).
- **Свободные каналы CANFD:** 6 модулей (`FLEXCAN8` – `FLEXCAN13` со своими индивидуальными областями ОЗУ сообщений).
- **Аналоговые модули:** 6 блоков АЦП (`ADC0` – `ADC5`) и 1 быстродействующий аналоговый компаратор (`CMP`).
- **Интерфейсы UART/LIN:** 13 аппаратных каналов (`FCUART0` и группа `FCUART2` – `FCUART13`).
- **Интерфейсы SPI:** 7 независимых контроллеров (`FCSPI0`, `FCSPI1` и группа `FCSPI3` – `FCSPI7`).
- **Шина I2C:** 1 канал (`FCIIC0`).
- **Специализированные таймеры:** 8 блоков гибких таймеров (`FTU`), 3 расширенных таймера (`eFTU`) и процессор обработки временных сигналов (`TPU`).
- **Автомобильная периферия:** Все каналы интерфейсов `SENT`, `SDDF` и микросекундных каналов связи `MSC`.

## 3. Шаблон инициализации регистров MUX (Bare-metal)

Пример написания кода на чистом Си для ручной инициализации портов (без использования китайской среды FC IDE):

```c
#include "FC7300.h"

void Board_Pins_Init(void) {
    /* 1. Активация тактирования портов в модуле PCC */
    PCC->PCC_PORTA |= PCC_PCC_PORTA_CGC_MASK;
    PCC->PCC_PORTB |= PCC_PCC_PORTB_CGC_MASK;
    PCC->PCC_PORTC |= PCC_PCC_PORTC_CGC_MASK;
    PCC->PCC_PTD   |= PCC_PCC_PTD_CGC_MASK;
    PCC->PCC_PORTE |= PCC_PCC_PORTE_CGC_MASK;

    /* 2. Настройка отладочной консоли UART1 (ALT4) */
    PORTA->PCR[18] = (4 << PORT_PCR_MUX_SHIFT); /* TX */
    PORTA->PCR[19] = (4 << PORT_PCR_MUX_SHIFT) | PORT_PCR_PE_MASK | PORT_PCR_PS_MASK; /* RX + PullUp */

    /* 3. Настройка CAN0 с функцией пробуждения Wakeup (ALT4) */
    PORTE->PCR[21] = (4 << PORT_PCR_MUX_SHIFT); /* FLEXCAN0_TX */
    PORTE->PCR[22] = (4 << PORT_PCR_MUX_SHIFT) | PORT_PCR_PE_MASK | PORT_PCR_PS_MASK; /* FLEXCAN0_RX */
}
```

## 4. Таблица выводов для подключения устройств программирования и отладки

Для обеспечения возможности внутрисхемного программирования, прошивки и аппаратной отладки (JTAG/SWD) микроконтроллера FC7300F8MDT на плате шилда необходимо развести следующие физические выводы. 

### 1. Спецификация сигналов отладочных интерфейсов

| Сигнал интерфейса | Пин BGA320 | Имя вывода (Pad) | Режим MUX | Тип Pad / Аппаратное состояние при сбросе | Назначение вывода |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **SWD_CLK** / JTAG_TCLK | **E7** | PTC4 | ALT0 (0x0) | PD0 / Pull-down (встроенный) | Тактовый сигнал для SWD или JTAG (вход). |
| **SWD_DIO** / JTAG_TMS | **B4** | PTA4 | ALT0 (0x0) | PD0 / Pull-up (встроенный) | Линия обмена данными для SWD или выбор режима JTAG (ввод/вывод). |
| JTAG_TDI | **C6** | PTC5 | ALT0 (0x0) | PD0 / Pull-up (встроенный) | Вход последовательных данных JTAG. |
| JTAG_TDO | **F8** | PTA10 | ALT0 (0x0) | PD0 / Output | Выход последовательных данных JTAG. |
| **RESET_b** | **B5** | RESET_b | Фиксированный | Dedicated / Pull-up (встроенный) | Линия аппаратного сброса системы (активный уровень — низкий). |
| **ISP_EN_B** | **H16** | PTD21 | ALT0 (0x0) | VDD_HV_A / Pull-up (встроенный) | Вход активации режима внутрисхемного загрузчика (Bootloader). |

> ⚠️ **Предупреждение:** Вывод `PTD21 (ISP_EN_B)` имеет критически важную логику работы. Если во время подачи аппаратного сброса (`RESET_b` прижимается к земле) на пине `PTD21` удерживается низкий логический уровень, микроконтроллер принудительно стартует не из Flash-памяти приложений, а переходит в режим заводского внутрисхемного программирования (ISP Mode) для восстановления прошивки через UART/CAN. Категорически запрещено использовать данный пин под другие задачи на шилде, если функция ISP включена в конфигурации NVR чипа.

### 2. Рекомендации по трассировке и схемотехнике разъема отладки

1. **Длина линий:** Дорожки от процессора до отладочного разъема (рекомендуется стандартный 10-пиновый Cortex Debug Connector с шагом 1.27 мм или 20-пиновый J-Link разъем) должны быть минимальной длины (не более 50 мм) во избежание искажения фронтов тактового сигнала `SWD_CLK` на высоких частотах отладчика (до 25-50 МГц).
2. **Внешняя подтяжка:** Несмотря на наличие встроенных в кристалл резисторов подтяжки, для работы в условиях индустриальных помех на линиях CANFD настоятельно рекомендуется установить внешние подтягивающие резисторы номиналом 10 кОм: к шине `VDD_HV_A` для линий `SWD_DIO`, `JDI`, `RESET_b` и `ISP_EN_B`, и к земле `GND` для линии `SWD_CLK`.
