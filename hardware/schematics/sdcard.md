# Подключение microSD к шилду FC7300

Анализ возможности добавления слота **microSD** в шилд (Этап 1) и предлагаемый вариант подключения.

> **Целевой чип:** Flagchip **FC7300F8MDT2A320T1B** (BGA320) — вариант, для которого
> существует поддержка в SDK (`FC7300F8MDT2A320T1B_feature.h`, SDK V2.6.0) и в пинауте
> `FC7300F8MDT Pinout_V1.3.xlsx`.

## Вывод (TL;DR)

| Вариант | Реализуемость | Скорость | Комментарий |
| :--- | :---: | :---: | :--- |
| **A. microSD в SPI-режиме на шилде (FCSPI5)** | ✅ **Рекомендуется** | до ~2.3 МБ/с | 4 сигнала + 3V3 + GND; все пины свободны |
| B. Встроенный microSD SBC (Sige7) | ✅ Уже есть | SDIO, до 100+ МБ/с | Для хоста (Armbian/Ubuntu), без доработок |
| C. Паянная Nano SD NAND (MKDN512GCL-ZC) на шилде | ✅ Альтернатива A | до ~2.3 МБ/с (SPI) | Нераспаянный вариант того же интерфейса |
| D. Нативный SDMMC / SDIO / eMMC на FC7300 | ❌ **Недоступно** | — | Контроллера в чипе нет (см. ниже) |

**FC7300 не имеет контроллера SD-карт (SDMMC/SDIO/eMMC).** Единственный штатный способ
подключить SD-карту — **SPI-режим карты** через один из 8 контроллеров **FCSPI**
(1 бит, режим 0, ≤ 25 МГц по спецификации SD).

---

## 1. Почему нет нативного SD-интерфейса

Проверено по официальному комплекту документации `Y:\Flagchip\FC7300 - документация`:

| Источник | Что проверено | Результат |
| :--- | :--- | :--- |
| `FC7300 Data Sheet_A4.pdf` | Периферия, тайминги, электропараметры | SDMMC/SDIO/eMMC нет; упоминания «SD» — только ESD. SPI-интерфейсы: 8× FCSPI + OSPI |
| `FC7300 Reference Manual_V2.2.pdf`, гл. 60 | «MSC» | **MSC = Micro Second Channel** — канал связи с внешними power-переключателями (FCL/SO/EN[3:0]/SDI[3:0]), **не** storage-контроллер |
| `FC7300F8MDT Pinout_V1.3.xlsx` | Все 320 ball'ов, MUX-таблица | Пинуты MSC0/MSC1 — сигналы управления питанием; SD-картных сигналов нет |
| SDK V2.6.0 (`Example/FC7300`) | Драйверы, примеры | Драйверов SDMMC/SDIO нет; есть FCSPI (Master DMA/IRQ/Polling, Slave IRQ) |
| Схемы демо-плат V1.0/V2.0 | Внешняя память | Только NOR Flash GD25Q32 (SPI) + EEPROM; слота microSD на демо-плате нет |

Дополнительные ограничения:

- **OSPI** (8-битный SPI под внешний flash) делит пины с Ethernet: по AN0001
  «OSPI и ENET — использовать в одном из двух». На шилде занят ENET (RGMII) → OSPI недоступен.
- Внутренний Program Flash FC7300 — до 8 МБ; внешняя память шилда — NOR GD25Q32 на **FCSPI2**.

## 2. Что даёт FCSPI (Reference Manual, гл. 55)

- Master/slave; до 4 PCS; настраиваемые CPOL/CPHA (нужен режим 0: CPOL=0, CPHA=0).
- 1-битный full/half-duplex (SD SPI использует 1-бит), 2/4-бит — half-duplex.
- TX/RX FIFO по 8 слов; DMA-поддержка (важно для записи логов).
- «Все FCSPI работают в Stop mode; **FCSPI0 — ещё и в Standby** (при наличии функционального такта)».

Гарантированные такты SCK в master-режиме, питание IO 3.0–3.6 В (Data Sheet, Table 32):

| Тип pad | Max SCK (master) | Теоретический пиковый поток (1 бит) |
| :--- | :---: | :---: |
| Normal pad | 15 МГц | 1.875 МБ/с |
| HS pad | 18.75 МГц | 2.34 МБ/с |
| UHS pad | 25 МГц | 3.1 МБ/с |

IO-домены FC7300: **VDD_HV_A / VDD_HV_B = 3.0–5.5 В** (на шилде — 3.3 В) → уровни
совместимы с картой microSD (3.3 В) без преобразования.

## 3. Выбор пинов (свободные на текущем пинауте шилда)

Занято на шилде (см. [`fc7300-hat-pinout.md`](fc7300-hat-pinout.md)): RGMII + SMI, 8× FLEXCAN,
UART1, I2C1, **FCSPI2 (NOR Flash)**, SWD/JTAG, RESET_b, ISP_EN_B.

Свободные FCSPI-инстансы и их пригодность:

| Инстанс | Свободные наборы пинов | Примечание |
| :--- | :--- | :--- |
| **FCSPI5 (ALT2, HS pad)** | **PCS0=C16/PTH16, SCK=E15/PTH17, SIN=E14/PTI15, SOUT=B16/PTI16** | ✅ **Рекомендуемый**: все 4 пины свободны, все HS pad → 18.75 МГц, компактный кластер |
| **FCSPI0 (ALT4, HS pad)** | **PCS0=B1/PTG21, SCK=F5/PTG23, SIN=C2/PTG22, SOUT=A2/PTF23** | ✅ Альтернатива; все HS pad. FCSPI0 — единственный, работающий в Standby (RM §55.4), — стоит зарезервировать под транспорт Этапа 2 (SPI к SBC) |
| FCSPI6 (ALT4 / DEFAULT) | PCS0=F2/PTI1 (или U3/PTI4), SCK=H1/PTF4 (или V1/PTH5), SIN=H2/PTF3 (или P6/PTH4), SOUT=J3/PTF5 (или R5/PTI3) | Фолбэк: Normal pad → 15 МГц |
| FCSPI4 (ALT2) | PCS0=B13/PTG18, SCK=F13/PTG19, SIN=E12/PTG20, SOUT=C12/PTH18 | Свободен, но пины разбросаны (B/C/E/F-столбцы) |
| FCSPI1 | PCS0/SCK/SIN/SOUT свободны, но **PCS3 занят** (PTD16/PTB17 — FLEXCAN2/4) | Работает, если нужен только PCS0 |
| FCSPI2 | — | Занят NOR Flash GD25Q32 |
| FCSPI3 | PCS1 имеет единственный ball W9/PTC0 — занят RGMII (ENET_RXD1) | ❌ Неприменим |

### Рекомендуемая разводка — FCSPI5 (ALT2, HS pad)

| Сигнал карты | Функция FCSPI5 | Ball BGA320 | Pad | MUX | Домен |
| :--- | :--- | :---: | :--- | :---: | :--- |
| CS (active low) | FCSPI5_PCS0 | **C16** | PTH16 | ALT2 | PD1, HS pad |
| SCK (CLK) | FCSPI5_SCK | **E15** | PTH17 | ALT2 | PD1, HS pad |
| MOSI (DI) | FCSPI5_SOUT | **B16** | PTI16 | ALT2 | PD1, HS pad |
| MISO (DO) | FCSPI5_SIN | **E14** | PTI15 | ALT2 | PD1, HS pad |
| VDD | 3.3 V (buck 12 V → 3.3 V / 3 A) | — | — | — | — |
| CD (мех. выключатель слота) | GPIO, свободный **PD0** (опция) | **A6** (PTE24) или **E9** (PTE25) | — | GPIO | **PD0** — детект живёт в Standby |
| CD (контакт карты, внутр. pull-up 50 кОм) | GPIO, опционально | любой свободный PD0 | — | GPIO | опционально |

> ⚠️ PD0/PD1: пины, не отмеченные «PD0» в пинауте, принадлежат зоне **PD1** и обесточиваются
> в Standby (AN0001 §5.2). Для работы SPI-карты это не критично (доступ к карте в RUN mode),
> но **линию CD стоит выводить на PD0-GPIO**, чтобы детект вставки/извлечения работал
> в глубоком сне.

### Таблица соединений

> **Важно:** в SPI-режиме SD карта использует 4 сигнала — `CLK`, `CMD`, `DO` (MISO),
> `DI` (MOSI). По SD-спецификации в SPI-режиме **линия CMD используется как chip select
> (CS, active low)** и является только-выходом хоста — это в точности соответствует
> сигналу PCS0 FCSPI. Отдельная CS-линия не нужна.

| Контакт слота | Подключение | Обвязка |
| :--- | :--- | :--- |
| VDD | 3V3 | 0.1 мкФ + 10 мкФ |
| CLK | FCSPI5_SCK — E15 (PTH17) | ESD-массив |
| CMD (= CS) | FCSPI5_PCS0 — C16 (PTH16) | ESD-массив; внешний pull-up 10 кОм к 3V3 (удерживать CS высоким при отсутствии карты и при старте) |
| DAT0 (DO) | FCSPI5_SIN — E14 (PTI15) | ESD-массив |
| DAT1 (DI) | FCSPI5_SOUT — B16 (PTI16) | ESD-массив |
| DAT2–DAT3, RST | Не подключать | SPI-режим — 1-битный |
| CD (мех.) | GPIO PTE24 (A6), PD0 | pull-up 10 кОм; IRQ по фронту |
| CD (контакт карты) | Опционально: GPIO (PD0) | Внутр. pull-up 50 кОм в карте; внешний pull-down 10 кОм к GND → линия H только при вставленной карте |
| WP | Не существует у microSD | — |

### Обвязка и правила

1. **ESD:** 4-канальная двунаправленная TVS/ESD-матрица с напряжением затухания
   **≤ 5.5 В** на CLK/CMD/DI/DO (напр., SMBJ3.3CA по линии либо готовая 4-канальная
   матрица 3.3 В). `SM24CANB-02HTG-L` (24 В, V_C = 55 В) для этих линий **не подходит**.
2. **Питание:** VDD карты — только с шины 3V3; не запитывать с 5 V (IO FC7300 до 5.5 В,
   но карта — 3.3 В). Убедиться, что CLK/CMD/DI/DO не переживают VDD (FCSPI выключать до снятия 3V3).
3. **Трассировка:** линии до слота — короче 10 см, GND-плоскость под дорожками;
   CS (CMD) — с pull-up 10 кОм; pull-up на MISO не требуется.
4. **Слот:** SMT-разъём microSD с механическим CD (10–11 сигналов), вывод CD на GPIO.
5. **Последовательность:** 3V3 на карту → ≥ 1 мс (tSTBY) → подача такта; при выключении —
   сначала снять такт/CS.

## 5. Ожидаемая производительность

| Режим | Такт SCK | Пик (теория) | Реалистичный sustained |
| :--- | :---: | :---: | :---: |
| FCSPI5, HS pad (ALT2) | 18.75 МГц | 2.34 МБ/с | ~2.0–2.3 МБ/с |
| FCSPI6 / Normal pad | 15 МГц | 1.875 МБ/с | ~1.6–1.8 МБ/с |

Оценка нагрузки логгера: 8× CAN FD × 8 Мбит/с = 8 МБ/с **пиково** (реальная утилизация
шин в автосети на порядок ниже). ~2 МБ/с достаточно для:

- OTA-прошивки FC7300 и хранения резервных образов (внутренний flash — 8 МБ);
- локального буферизованного логирования (fallback, когда SBC недоступен);
- экспорта данных со стороны FC7300.

**Основное хранилище логгера — eMMC/NVMe SBC (Sige7), а не SD на шилде.**

## 6. Программная часть

1. **Драйвер FCSPI** — в SDK: `Template/Driver/Source/module_driver_fcspi.c` + HwA
   (`HwA_fcspi.h`), примеры `Example/FC7300/FCSPI/FCSPI_Master_DMA|Interrupt|Polling`.
2. **SD-карта в SPI-режиме** — стандартная инициализация по SD-спецификации:
   ≥ 74 такта idle → CMD0 (0x40) → CMD8 (0x40, 0x1AA) → ACMD41 (0x41) → CMD58 (OCR) →
   чтение CSD/CID. В RT-Thread из SDK есть готовый стек:
   `components/drivers/spi/spi_dev.c` (SPI-шина) + `spi_msd.c` (SD-карта поверх SPI)
   → блочное устройство `/dev/msd0`.
3. Настройка FCSPI5: master, WIDTH=1 (1-бит), SCK_PHA=0/SCK_POL=0 (режим 0),
   PRESCALE так, чтобы SCK ≤ 18.75 МГц; PCS0 активный низкий.
4. **Standby:** FCSPI5 не работает в Standby (только FCSPI0); доступ к карте — в RUN mode.
   Детект вставки карты в Standby возможен через CD-GPIO (PD0).

## 7. Альтернатива C: паянная Nano SD NAND (MKDN512GCL-ZC)

Если сменные карты не нужны, вместо слота можно распаять **MKDN512GCL-ZC**
(Nano SD NAND, 512 Gbit ≈ 64 ГБ, TLC, LGA-16 9×13 мм, даташит — `hardware/pdf/nand/`):

- Подключается **по тому же FCSPI5 в SPI-режиме** (карта поддерживает SD и SPI режимы,
  до 208 МГц в SD-режиме; в SPI — ограничено тактом FCSPI).
- Отличие от слота: вывод **CD (пин 1) подтянуть к GND** (10 кОм) — по даташиту выбор
  SPI-режима происходит при низком уровне CD на момент подачи питания.
- VDD = 3.3 В, CLK/CMD/DI/DO — аналогично таблице выше.
- Минусы: неремонтируемо, без детекта; плюс: 64 ГБ фиксированной памяти,
  выше ресурс записи (встроенный ECC, wear leveling).

## 8. Встроенный microSD SBC (вариант B — уже есть)

ArmSoM Sige7 имеет собственный слот microSD (см. `../bom.md`, раздел SBC:
«Storage: 64/128 GB eMMC, MicroSD card slot»). Это **полноценный SDMMC-интерфейс RK3588**
— для хостовой ОС и пользовательских данных достаточно штатного слота SBC,
без каких-либо доработок. Слот на шилде (вариант A) нужен только для хранилища
**самостоятельно** от FC7300 (OTA / локальный буфер / автономный лог).

## 9. Итоговые рекомендации

1. **Добавить SMT-слот microSD на шилд, подключить к FCSPI5 (ALT2, HS pad)**:
   C16/E15/B16/E14 + 3V3 + CD на PTE24 (PD0). Все пины свободны, конфликтов с
   текущим пинаутом нет.
2. FCSPI0 (HS pad: B1/F5/C2/A2) **не задействовать** — зарезервировать под SPI-транспорт
   Этапа 2 (FC7300 ↔ SBC), т.к. он единственный работает в Standby.
3. ESD-защита — 4-канальная двунаправленная матрица ≤ 5.5 В (не SM24CANB).
4. Рабочий режим: **SPI 1-бит, mode 0, ≤ 18.75 МГц** (~2.3 МБ/с). Для основной записи
   логов использовать eMMC/NVMe SBC.
5. Рассмотреть **MKDN512GCL-ZC** (SPI-режим, тот же FCSPI) как вариант фиксированного
   64 ГБ хранилища вместо слота — или оставить слот для сервисной гибкости.
6. Не закладывать в ожидания: SDMMC/SDIO/eMMC на FC7300 (нет контроллера),
   HS400/UHS-режимы карты (нужен 1.8 В SDMMC-хост — отсутствует).
